# Online-Banking
An Online-Banking website with responsive frontend with backend admin, crud functionalities
🚀 Features

🔐 Authentication & Security
	•	JWT-based authentication
	•	Encrypted user credentials
	•	Role-based access control (Admin/User)
	•	Protected routes for financial operations

💳 Banking Operations
	•	Create and manage user accounts
	•	Deposit & withdrawal operations
	•	Internal fund transfers
	•	Transaction tracking with timestamps
	•	Automated balance reconciliation

📊 Transaction Engine
	•	Robust validation and error handling
	•	Prevention of double-charging and race conditions
	•	Full audit logging for all financial actions

🗄 Database Layer
	•	MongoDB for user data & account storage
	•	SQL Server / MongoDB for transaction logs (depending on your setup)
	•	Well-structured schemas for scalability

🧪 Testing
	•	Thorough API testing using Postman or Thunder Client
